# Python Web Scraper

## Overview

This project is a Python web scraper built with Requests and BeautifulSoup. It extracts information from websites and saves the results in a structured format.

## Features

- Extracts website data
- Parses HTML content
- Saves data to CSV
- Easy to customize
- Clean and organized Python code

## Technologies

- Python
- Requests
- BeautifulSoup4

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python scraper.py
```

- Web Scraping
- HTML Parsing
- Data Extraction
